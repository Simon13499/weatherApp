# Weather App

A responsive weather application built with vanilla JavaScript and Tailwind CSS.

The application uses the Open-Meteo API to display current weather conditions and forecasts for searched cities.

## Features

- Search weather by city
- Current temperature, wind speed, humidity and precipitation
- 3-day weather forecast
- Interactive hourly weather forecast
- Last searched city saved in localStorage
- Responsive design

## Technologies

- HTML5
- JavaScript (ES6+)
- Tailwind CSS
- Open-Meteo API

## Getting Started

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Run the Tailwind compiler:

   `npx @tailwindcss/cli -i ./src/input.css -o ./output.css --watch`

4. Open `index.html` in a browser.

## API

Weather data is provided by [Open-Meteo](https://open-meteo.com/).
